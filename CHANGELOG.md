- Исправлен HTTP 415 при загрузке новостей GitHub Releases.
- Добавлена кнопка переключения на Fortnite с диагностикой отказа Windows.
- Обычные релизы выпускаются GitHub Actions после успешной проверки и сборки, без ручной публикации тега.
- **Важно:** автоматическое нажатие «Играть снова» ещё требует проверки в реальном матче; непрерывная ночная работа и отсутствие ограничений аккаунта не гарантируются.

- Новости автоматически показывают последние опубликованные GitHub Releases (в случае отсутствия сети остаются локальные записи).

- Работа Win32 SendInput внутри Fortnite не может быть гарантирована, поскольку игра может блокировать синтетические нажатия.

## v1.3.3 — исправления анти-АФК и диагностика ввода

- Встроенный тест Windows-ввода **W** в активном Fortnite (F6 или кнопка с задержкой 3 секунды).
- Отдельный безопасный тест ввода в Блокноте: помогает отделить отказ стандартного Windows SendInput от неподдерживаемого ввода в игре.
- Видимые причины остановки ввода: Fortnite не найдена / найдена, но не активна / Anti-AFK выключен.
- Движок корректно запрашивает остановку и ждёт завершения долгого захвата экрана без зависания интерфейса. Удерживаемые клавиши при остановке прерываются.
- Распознавание шаблонов прерывается между шагами при остановке/паузе; нельзя запустить второй движок, пока первый останавливается.
- Уточнена идентификация окна Fortnite: процесс предпочтительнее совпадения по заголовку случайного окна.
- Сохранены v1.3.2: обновления через GitHub, демо-экран подписок, настройки, статистика, шаблоны.
- Важно: успешный SendInput подтверждает отправку события в Windows, но НЕ гарантирует, что Fortnite обработает ввод; обход античита не реализован.
