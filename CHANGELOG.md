# Changelog

## 1.3.0 — 11 ноября 2026
- Отдельная вкладка Anti-AFK с переключателями для ходьбы, диагоналей, спринта, прыжков, подката, камеры и слотов.
- Случайные последовательности с паузами 0,5–2 секунды и защитой от одинакового действия подряд.
- Камера: относительные перемещения мыши, повороты и приблизительный возврат к центру; настройка чувствительности.
- Опциональные ЛКМ, Y+ЛКМ, слот 2 + ПКМ + ЛКМ (непродолжительный залп).
- Новые шаблоны Death и Replay: после обнаружения смерти движения блокируются до нажатия «Играть снова».
- Клавиши отпускаются при остановке и потере фокуса; F8 — стоп, F10 — пауза.
- Не реализованы: точное определение патронов, безопасная очистка инвентаря, универсальное распознавание кнопок без образцов.
- Тесты последовательностей, сохранения настроек и реакции на смерть/Replay.

## 1.2.4 — 11 ноября 2026
- Пиратский токен в иконке и интерфейсе, убрана надпись Gold Edition.
- Локализован переключатель языков, русские/английские/украинские подписи; внутренний код украинского языка по стандарту `uk`.
- Обновлена главная страница: компактные управление, статус сессии и гайд сверху, пояснение графика за последний час.
- Редактируемый множитель калькулятора удачи, сохранение значения и отключение автоматического множителя при ручном изменении.
- Реализована проверка GitHub Releases для установленного приложения, подтверждение установки, SHA-256 проверка установщика.
- Добавлены скрипты публикации ветки и тегов через Git пользователя, GitHub Actions для создания Windows-установщика и контрольной суммы.
- Добавлены автономные регрессионные тесты GitHub-обновлений.

## 1.2.3 — 2026-11-11

- Better status diagnostics for game focus, number of input attempts, input errors.
- First movement event occurs promptly, no screenshot scanning when templates are absent.
- Optional diagonal key holds with `try/finally` release.
- Windows EXE and Inno Setup build scripts and per-user data directory.
- Static competitor installer research only; no proprietary code copied.

## 1.2.2 — 2026-11-11
- Исправлено событие готовности JS/Python API (window вместо document).
- Ожидание с резервной проверкой и видимыми ошибками запуска.
- Безрамочное окно с собственными кнопками управления, визуально скруглёнными панелями.
- Резервный запуск `run-classic.bat`.
