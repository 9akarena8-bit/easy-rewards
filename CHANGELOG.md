## v1.4.1 Beta — исправление зависания запуска Anti-AFK (12 ноября 2026)

- На основе первого пользовательского отчёта v1.4.0: команда Start получена Python, но движок остаётся остановленным, журнал пуст, иногда появляется Python API timeout.
- Запуск движка больше не ждёт синхронных вызовов Windows для поиска/активации окна Fortnite: работа идёт в отдельном потоке, интерфейс получает быстрый ответ.
- Запрос открытия Fortnite через Epic Launcher или активации уже открытого окна выполняется отдельно после запуска движка.
- Отмена запуска через Stop предотвращает неожиданный старт после длительной задержки.
- В отчёт поддержки добавлены этап запуска, ожидающий запуск и последняя ошибка. UI явно сообщает, что старт только принят в очередь.
- Тесты моделируют зависание поиска окна и отмену запуска; дополнены существующие тесты.
- Это тестовая сборка, работа Anti-AFK в настоящем Fortnite и соответствие игровым правилам ещё не подтверждены. Оплата и Steam-trades по-прежнему отключены.

## v1.4.0 Beta — Alt+Tab без зависаний, управление из Fortnite и новый лаунчер

- Главная v2: возвращена утверждённая тёмно-синяя/золотая палитра, море, пиратский корабль и закат через сохранённую CSS/SVG-адаптацию из ветки дизайна PR #13. Компоновка главной не менялась.

- Переключение Alt+Tab **приостанавливает** анти-AFK: после возвращения в игру программа не начинает действия самопроизвольно. Продолжение — назначенной кнопкой или F10, когда Fortnite снова активен.
- При потере фокуса отменяется текущее удержание клавиш и отбрасывается кадр, полученный до переключения окна. Переключение между приложениями не вызывает постоянного принудительного возврата в Fortnite.
- Кнопки запуска, остановки и паузы/продолжения настраиваются в лаунчере. F10 остаётся резервным продолжением, F12 — экстренным стопом. Совпадающие комбинации не принимаются.
- По команде «Запустить» лаунчер пытается открыть Fortnite через Epic Games Launcher, если окно игры отсутствует. Отправка команды не означает гарантированного запуска; диагностика показывает фактическое состояние.
- Сохранён оригинальный пиратский жетон с буквой F, улучшен тёмно-золотой интерфейс, добавлены видимый статус Alt+Tab и отчёт для бета-тестирования.
- Подписки и способы оплаты (карты, СБП, QR, Telegram Stars, Steam-скины) остаются **демонстрацией без реальных списаний и выдачи платного доступа**.
- Установщик предназначен только для двухэтапного тестирования на Windows и не является коммерческим релизом. Работа в Fortnite и соблюдение игровых правил требуют отдельной проверки.

- Добавлена кнопка переключения на Fortnite с диагностикой отказа Windows.

# Easy Rewards — История версий

## v1.3.3 — исправления анти-АФК и диагностика ввода

- Встроенный тест Windows-ввода **W** в активном Fortnite (F6 или кнопка с задержкой 3 секунды).
- Отдельный безопасный тест ввода в Блокноте: помогает отделить отказ стандартного Windows SendInput от неподдерживаемого ввода в игре.
- Видимые причины остановки ввода: Fortnite не найдена / найдена, но не активна / Anti-AFK выключен.
- Движок корректно запрашивает остановку и ждёт завершения долгого захвата экрана без зависания интерфейса. Удерживаемые клавиши при остановке прерываются.
- Распознавание шаблонов прерывается между шагами при остановке/паузе; нельзя запустить второй движок, пока первый останавливается.
- Уточнена идентификация окна Fortnite: процесс предпочтительнее совпадения по заголовку случайного окна.
- Сохранены v1.3.2: обновления через GitHub, демо-экран подписок, настройки, статистика, шаблоны.
- Важно: успешный SendInput подтверждает отправку события в Windows, но НЕ гарантирует, что Fortnite обработает ввод; обход античита не реализован.
