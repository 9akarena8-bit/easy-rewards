# Автозапуск из лобби — Fortnite Pirate Token v1.4.1 Beta

## Что подготовлено

Движок умеет обнаруживать сохранённые образцы кнопок `lobby_play`, `lobby_ready`, `lobby_confirm` и **проверять вход в матч** по отдельному `match_hud`. Кнопки без подтверждения распознавания не нажимаются. Повторные нажатия ограничены. Перед кликом всегда перепроверяется активное окно Fortnite.

## Как один раз настроить на своём ПК

1. Открой Fortnite в режиме окна без рамки и перейди в лобби.
2. В Fortnite Pirate Token открой **Шаблоны**, выбери **«Лобби: кнопка „Играть“»**, нажми **«Захват»** и выдели на снимке саму кнопку вместе с текстом. Сохрани шаблон.
3. Если после неё появляется другая кнопка, так же сохрани её в роли **«Лобби: „Готов“ / „Начать“»**. При отдельном подтверждении добавь **«Лобби: подтверждение»**.
4. Зайди в матч вручную. В разделе **Шаблоны** сохрани в роли **«В матче: элемент HUD»** небольшой, отчётливо различимый элемент HUD, **которого нет в лобби и на экране загрузки** (не просто однотонную полоску).
5. На странице **Анти-АФК** включи «Запускать матч из лобби (по образцам)». Проверь статус распознавания через тест шаблонов. Кнопка должна совпадать выше 0.88, два раза подряд.
6. Запусти Anti-AFK горячей клавишей, по умолчанию F7. При Alt+Tab программа останавливает действия до ручного возобновления; F12 — экстренная остановка.

При наличии образца кнопки лобби и отсутствии образца HUD программа **не будет автоматически выполнять движения**, потому что не умеет достоверно определить начало матча.

## Ограничения

- На предыдущем пользовательском видео (12 ноября, ~92 секунды) показан уже начавшийся матч и интерфейс лаунчера; последовательность кнопок лобби отсутствует. Поэтому образцы точных игровых кнопок не встроены.
- Движок не утверждает, что Fortnite принимает стандартный Windows SendInput в защищённом клиенте. Проверка в реальной игре не выполнена.
- Не пытаться обходить EAC. Правила Epic могут запрещать игровую автоматизацию. Коммерческий запуск до проверки недопустим.
- Локальная демо-оплата и Telegram Stars не активируют автоматизацию. Продающие платежи по умолчанию отключены.
- Все распознаваемые кнопки, HUD и статистика берутся из локальных пользовательских шаблонов; чужие аккаунты и учётные данные не требуются.
