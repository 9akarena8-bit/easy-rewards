## Обязательная навигация и shell

- Слева **ровно 5 пунктов**: **Главная / Подписка / Новости / Поддержка / Настройки** (Настройки внизу), без «Шаблонов», «Статистики» и отдельной публичной страницы Anti-AFK. Не удалять рабочий backend этих функций, перенести технические настройки в «Дополнительно/Диагностика».
- Оригинальная монета-компас с белой **F** (не перерисовывать) и **соломенная шляпа на слове FORTNITE на каждом экране**. Убрать случайную звезду/корону над T и декоративный мазок под PIRATE TOKEN.
- Привести поддержку/настройки из слишком синей гаммы к общей тёмно-фиолетовой + умеренные золотые акценты. Сохранить композицию по фото.
- Реальная HTML/CSS/JS-разметка, а не единый скриншот как фон с невидимыми кнопками. Один основной скролл, состояния, клавиатура, адаптивность 1366×768/1920×1080/mini-mode, локали RU/EN/UK/FR/PL/AR (арабский RTL).
- Проверить права на коммерческое использование любых сторонних персонажей/официальных игровых изображений до публичного распространения.

## Контракты страниц

**Главная:** «Запустить» → `start()`, «Пауза/Продолжить» → `pause()`, «Остановить» → `stop()`; реальные `state()` и HWND Fortnite, корректные загрузка/ошибка/стоп. Alt+Tab — пауза и **только ручной** Resume, F7/F8/F10, аварийная F12. Удалить макетный блок «Автовосстановление». Новости и сроки подписки **не фейковые**: рисовать только данные backend/API; никаких нарисованных 17 дней/премиум-статусов.

**Подписка:** 1/3/7 дней — **59/129/249 ₽**; без придуманных зачёркнутых скидок и привилегий. При «Выбрать» открывается **внутренняя** панель оплаты из первого макета, **плавно появляется слева** согласно последнему решению #24 (рисунок сам по себе не задаёт сторону анимации). Основная страница с затемнением 40–50% и blur(5–7px); Esc/клик вне/× закрывают, удерживать scroll/focus/tariff. Методы клиента: перевод СБП/карта с ручным подтверждением владельца, Steam-скины после верификации trade; без реальных реквизитов не включать оплату. Приватная админка **не** в клиентском меню. `SALES_ENABLED=0` до серверной приёмки.

**Рефералы:** модал «Пригласить друга» с двумя персонажами; серверная уникальная ссылка и **10% обоим только после первой подтверждённой покупки** нового пользователя. Не переносить фиктивные `fptoken.ru/r/...`, счётчики «3 приглашено»/«1 покупка». Нужна связка auth account_id → verified order → entitlement, защита self-referrals/refunds.

**Новости:** сохранять уже готовую реализацию PR #31: архив реальных Releases/CHANGELOG, большой **центральный** патч-модал поверх blur ленты, отдельный скролл полного текста, «К новостям», Esc/фон/×, восстановление scroll. Даты/версии/изменения из GitHub, не из макета. Офлайн-патчи тоже открываются.

**Поддержка:** настоящий FAQ по подписке/не найден Fortnite/Alt+Tab/обновлениям/ожидающей заявке. `create_support_report()` с предпросмотром и копированием, без ложного заявления «запрос отправлен», если нет API. Telegram `https://t.me/uuuui44` и `@zaka3Hble_y6uucTBa` ранее фигурировали как разные контакты: уточнить роль перед публикацией. Не выдумывать Discord-сервер, email или «24/7». Discord webhook — личные уведомления в настройках, не публичная кнопка поддержки.

**Настройки:** dark/light theme, языки RU/EN/UK/FR/PL/AR + RTL, реальные переключатели `set_config()` и проверка `ok/rejected/save_failed` до «Сохранено»; F7/F8/F10/F12, Alt+Tab, обновления (`update_check_async()` и `state().update`), Discord `discord_configure/test/clear` без показа секрета. Не рисовать фальшивые «запуск Windows»/«сворачивать в трей» без backend. Автооткрытие лаунчера с Fortnite — только #36, **не** автоматический старт Anti-AFK.
