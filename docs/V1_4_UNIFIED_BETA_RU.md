# Fortnite Pirate Token v1.4.0 — объединение всех обновлений

Дата: 12 ноября 2026. Назначение: единая Windows Beta для самостоятельного тестирования.

## Источники и приоритеты
- main v1.3.9 — включает PR #1–#10: обновления, трекер/статистика, шаблоны, Anti-AFK, поддержка, Discord, SkinPay.
- PR #12 — база новой реализации: управление и ручное продолжение после Alt+Tab, запуск Fortnite через Epic Launcher, утверждённый новый дизайн, локальная диагностика. Не подменять старым вариантом PR #13.
- PR #13 — добавлена последовательность подката, тесты и инструкции. Разные реализации Alt+Tab несовместимы, выбрана более новая из PR #12, требующая подтверждения пользователя после Alt+Tab.
- PR #11 — безопасный конфиг, проверки типов/диапазонов, миграция hotkeys, защита черновиков.
- PR #14 — Stars-бот, демо-касса, SQLite, опциональная серверная проверка лицензии и тесты.

## Проверка после установки
1. Открыть лаунчер. Проверь главную: F-токен, тёмная золотая тема, новости версии и страницы трекера/настроек/подписок.
2. Запустить Fortnite вручную или командой из лаунчера. Начало работы зависит от окна Fortnite, успешной отправки команды запуска недостаточно.
3. Запустить Anti-AFK в тестовой среде, проверить F7, F8, F10, F12 и переназначенные клавиши. После Alt+Tab убедиться, что действует пауза, клавиши отпущены, а повторное продолжение работает.
4. Проверить отчёт «Поддержка», автоматическое «Играть снова», шаблоны и корректность игровых счётчиков.
5. Проверить SkinPay: добавить предметы в демо-корзину. Реальных обменов, котировок или транзакций не будет.
6. Открыть демо-кассу через merchant_service/START_DEMO.bat, если запускаешь исходники; сервер и бот запускаются отдельно от Windows-установщика. Для лицензии нужен собственный HTTPS-сервер; без него кнопка недоступна.
7. Пройти все CI-тесты и ручные проверки в Windows 10. В реальной игре автоматический ввод может не работать из-за защиты.

## Не реализовано
Реальные карточные/СБП/QR/банковские платежи; проверенные Steam-трейды и цены; оплачиваемые подписки с принудительным ограничением функций; подтверждённая работа Anti-AFK в защищённой игре. Не заявлять полноценный коммерческий выпуск. Возможны ограничения по правилам Epic/Steam.

## Почему это не автоматическое слияние четырёх PR
PR #11/#12/#13 редактируют core.py и hotkeys; PR #12/#13 меняют обработку Alt+Tab и UI; PR #12/#14 одновременно меняют backend.py и ui/app.js. Объединение сделано точечно без возврата к старым методам.
