# Fortnite Pirate Token — доступ владельца, друзей и ручная оплата

**Статус:** патч к локальному исходному снимку, не публичный релиз и не подписанный Windows EXE. Не менять логотип и утверждённые шесть экранов. Не делать merge/commit автоматически.

## Модель доступа

| Кому | Способ выдачи | Срок | Админ-права |
| --- | --- | --- | --- |
| Владелец | Локальная панель, метод `owner` | Бессрочно | Лишь в отдельной локальной панели, при наличии приватного ключа и пароля |
| Друг | Код `FPT2.…` либо JSON, метод `friend` | Бессрочно или ограниченный | Нет |
| Покупатель | По подтверждённому владельцем переводу или Steam-обмену | 1/3/7 дней (59/129/249 ₽) | Нет |

Подписанные документы привязаны к `installation_id`. Код активации — это не ссылка и не право администратора. Публичный ключ `assets/license-public.pem` встроен в сборку, приватный `private-key.pem` хранится **только** в `%LOCALAPPDATA%\FPT-Owner-Licensing`, под паролем. Административной кнопки или API выдачи лицензий в клиенте нет.

## Действия владельца на Windows

1. Примените патч к исходной рабочей копии с резервной копией; не заменяйте файлы, которые с момента экспорта изменились.
2. Откройте `OWNER_PANEL.bat` на **своём** компьютере, нажмите **Подготовить ключи**, задайте пароль минимум из 12 символов и сохраните его надёжно. Перегенерация ключей аннулирует совместимость старых лицензий.
3. Один раз запустите `COPY_PUBLIC_KEY.bat`. Он копирует **только публичную часть** в `assets/license-public.pem`; если там несовместимый ключ, операция останавливается.
4. Запустите тесты: `py -3.11 -m pytest -q merchant_service/tests tests/test_offline_access_bridge.py` и `node --test tests/browser_controls.test.cjs tests/skinpay_ui.test.cjs`.
5. Для локальной тестовой сборки запустите `BUILD_INSTALLER.bat`. Установщик может создаться только при наличии публичного ключа. Проверьте результат на своей Windows 10, прежде чем отправлять друзьям. Сборка и запуск на Windows **не подтверждены здесь**.
6. Откройте лаунчер, вкладку **Подписка**, скопируйте **Код установки**. В `OWNER_PANEL.bat` выберите **Бессрочно — только владелец**, введите код установки, пароль, нажмите **Выдать и сохранить файл доступа**; сохраните JSON **за пределами приватной папки**.
7. Нажмите **Копировать последний код доступа**. В лаунчере введите код `FPT2.…` → **Активировать доступ**. Должно появиться «Бессрочно · Лицензия владельца». Приватный пароль в клиент не вводится.

## Друг

Получает обычный установщик, копирует свой код установки, отправляет владельцу. Владелец выбирает **Бесплатно — друг**, срок **Бессрочно**, выдаёт JSON либо копирует код активации. Друг активирует его точно так же. Никакой административной панели, кода мастер-ключа или пароля не получает. Лицензия не переносится на новый компьютер без новой выдачи.

## Покупатель — банковский перевод / Steam-скины

В лаунчере покупатель выбирает 1/3/7 дней, **Перевод** или **Оплата скинами**, нажимает **Скопировать заявку** и связывается с владельцем. Это **не** платёжная касса и **не** подтверждение оплаты. Реквизиты, Steam-обмен и оценка предметов согласуются лично с владельцем вне лаунчера. Владелец проверяет поступление в своём банке или фактический окончательный Steam-трейд, вводит тот же код установки в приватную панель, выбирает способ и срок, ставит галочку личной сверки и выпускает **оплаченную** срочную лицензию. Скриншоты, заявления и статус демо-заказа не доказывают оплату; в случае неопределённого удержания/отмены обмена доступ не выдавать. Отсутствует автоматическое отслеживание платежей и трейдов. `SALES_ENABLED=0` оставлен без изменения.

**Важно:** без сервера нельзя выдавать онлайн-ссылки, автоматически блокировать/отзывать уже выданные бессрочные лицензии или надёжно предотвращать обход на модифицированном клиенте/часах Windows. Для будущих удалённых отзывов, настоящей реферальной схемы и оплаты через приложение потребуется серверная идентификация и проверка транзакций. Бессрочная бесплатная лицензия — сознательный выбор владельца.

## Технические изменения

- Расширена подпись: v1 срочная лицензия без изменения формата; v2 `expires_at=null` доступна только `owner` и `friend`. Локальный парсер принимает JSON либо `FPT2.<base64url>` и проверяет Ed25519, `installation_id` и `issued_at`.
- В приватной панели добавлены типы owner/friend, бессрочный срок и копирование кода.
- `backend.offline_activate` принимает новый код, отображает `offline_access` и не даёт прав выдачи.
- UI отображает «Бессрочно» для бессрочных лицензий и формирует копируемую ручную заявку на оплату. Новых реальных платёжных адресов нет.
- Сборщик клиента не должен включать `owner_access`, `merchant_service.owner_license` и `merchant_service.private_demo`. Сам `private-key.pem`, база и пароль не должны быть ни в дереве исходников, ни в ZIP, ни в установщике.
- Не менялись игровые действия, логотип и макеты.

### Известные ограничения проверки

Тесты подписи/сроков/подмены лицензии и пользовательских заявок выполнялись в изолированном Linux окружении, не в установленном Windows EXE. Старый тест `app.main()` с флагами `--classic/--cli` ожидает Windows и не проходит на Linux из-за явной защиты `if sys.platform != "win32"`; на Windows нужно запустить полный pytest. Нет подтверждения реального запуска Fortnite, безопасности от блокировок или проверки реальных платежей.
