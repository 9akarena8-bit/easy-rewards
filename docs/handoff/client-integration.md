# Клиентская интеграция оплаты и доступа

- Выбор тарифа открывает оформление с двумя способами ручной оплаты. Суммы из макета: 59, 129 и 249 ₽. Пока реквизитов и ссылки обмена нет, экран показывает это и предлагает связаться с владельцем.
- Пользователь может скопировать ID установки, выбрать файл лицензии JSON или вставить его содержимое. Клиент проверяет подпись, ID и срок. При ошибке ранее сохранённый доступ сохраняется.
- В упакованном приложении действующая лицензия нужна для запуска и продолжения. Проверка срока останавливает работу независимо от открытого экрана. Флаги старого интерфейса и переменная FPT_OWNER_TEST не отключают проверку в EXE. Режим разработки из исходников сохранён.
- Проверено 12 существующих тестов интерфейса и 4 новых теста клиентской интеграции. Проверена применимость патча к общей копии. Реальный перевод, Steam-обмен, упакованный EXE и запуск в Fortnite не проверялись.
- Перед сборкой нужно включить публичный ключ владельца как assets/license-public.pem и проверить наличие cryptography в сборке. Закрытый ключ остаётся у владельца.
