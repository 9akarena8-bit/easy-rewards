# Source preflight перед Windows beta (v1.4.3)

Контекст: #21, #22, #25, #35, #37, #38. Этот инструмент **не меняет код приложения и не отправляет ввод в Fortnite**.

## Зачем

Проверка от 12.11.2026 выявила: #37 (`5b39fe9`) интегрировал #26 на старом SHA `c3cc816`, тогда как новый head #26 — `3a8821f`. В интеграционном кандидате отсутствуют обновлённые Python API и очистка горячих клавиш. GitHub CI старого SHA был зелёным, поскольку тестировал более старую реализацию.

Проверка `scripts/candidate_preflight.py` ищет **обязательные исходные API/маркеры** в рабочем дереве кандидата. Отдельно можно сверить `--expected-sha` с SHA, указанным для Windows-установщика.

## Запуск на кандидате

Сначала checkout **точного** SHA будущей сборки (после cherry-pick и согласования с ответственными), затем:

```powershell
py -3.11 scripts/candidate_preflight.py . --expected-sha 0123456789abcdef0123456789abcdef01234567
py -3.11 scripts/candidate_preflight.py . --json
py -3.11 -m pytest -q tests/test_candidate_preflight.py
```

Заменить `0123...` на реальный **полный 40-символьный SHA** кандидата. Код завершения: 0 — все статические проверки пройдены; 1 — отсутствие обязательного контракта, файла либо mismatch SHA; 2 — неверные CLI-аргументы. JSON не включает содержимое файлов, токены или персональные данные.

**Fail — блокирующий повод для анализа интеграции, не команда автоматически переносить весь PR.** Проверки regex подтверждают только присутствие исходного контракта, **не корректность поведения**.

## Что проверять вручную до релиза

- CI quality/Windows installer относится **именно к SHA интегрированной сборки**, а не к независимому #26/#28/#31.
- Один и тот же EXE/SHA256 на обоих Windows ПК; Start/Pause/Resume/Stop/F12/Alt+Tab, отмена старта, WinIO в двух вариантах процесса; нет авто-возобновления ввода.
- Пять утверждённых вкладок, локальные новости и Esc, поддержка без секретов, настройки и шесть языков/RTL, 1366×768 и 1920×1080, mini-mode (матрица #38).
- `SALES_ENABLED=0`; демо-заказ не подтверждает реальные деньги и не выдаёт право; отдельно проверить будущую серверную лицензию/админку, только на стенде.
- Сохранить точный source SHA + SHA256 **EXE**, результат каждого из двух тестировщиков и решение о релизе в #25/#21.
