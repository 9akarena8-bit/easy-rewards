# Fortnite Pirate Token — проверка Anti-AFK и нового UI (тестовая ветка)

Это тестовая ветка PR #13, а не публичный релиз. Не объединяйте ветку в main, пока не пройдены Windows CI и ручная проверка.

## Кнопки и фокус

1. Запустите Fortnite вручную и дождитесь появления игрового окна.
2. Откройте Fortnite Pirate Token, вкладка **Анти-AFK**.
3. В блоке **Горячие клавиши** настройте «Запуск», «Остановка», «Пауза». По умолчанию: **F7 / F8 / F10**.
4. F6 всегда зарезервирована для диагностики; F9 — для счётчика. Одинаковые горячие клавиши назначить нельзя.
5. Нажмите **Запустить** в лаунчере. При включённом auto_focus и обнаруженном окне Fortnite программа сворачивает свой интерфейс и делает обычный запрос Windows на фокус игры.
6. Если Windows не позволяет переключение, вернитесь в приложение через Alt+Tab и проверьте **Диагностику**: статус окна, foreground process и результат focus. Можно вручную перейти в игру.
7. F8 (или выбранная кнопка) должна немедленно остановить движок; F10 (или выбранная кнопка) — поставить на паузу.

## Проверка Alt+Tab и паузы

1. Сначала включите Anti-AFK и проверьте, что Fortnite является активным окном.
2. Нажмите **Alt+Tab** на Рабочий стол или в браузер. Программа должна перейти в **Автопауза**: действия прекращаются, Fortnite не вытесняется поверх других окон.
3. Вернитесь в Fortnite. Через небольшую защитную задержку движок должен возобновить работу, не используя старый кадр интерфейса.
4. Нажмите **Пауза** (по умолчанию F10), затем **Alt+Tab**, затем снова вернитесь. Ручная пауза должна сохраниться до второго нажатия F10.
5. Проверьте, что во время переключения окна в браузере или Блокноте не появляются случайные нажатия программы.
6. Кнопка **Стоп** (F8 по умолчанию) должна останавливать работу из любого окна.

Отображение «Команда отправлена» означает отправку события Windows — не подтверждение движения в Fortnite. При блокировке ввода защитой игры следует остановить тест; обход защиты не реализован.

## Отдельный тест обработки ввода

- В интерфейсе уже предусмотрен **Тест в Блокноте (W)**. Он позволяет проверить обычный Win32 SendInput без игры.
- Если Блокнот печатает W, это **не доказывает**, что Fortnite принимает ввод: проверьте F6 в активном окне Fortnite и поле последней диагностики.
- Если клиент не реагирует на Windows SendInput, не пытайтесь обходить античит и не обещайте покупателям гарантированную автоматизацию.
- В журнале «Команда отправлена» отражает вызов Windows, а не подтверждённое действие в самой игре.
- При зависании захвата экрана F8 должен оставаться отзывчивым.

## Оплата и дизайн

- Источник дизайна: утверждённый пользователем «Fortnite_Pirate_Token_Design_v2_Characters_Approved.png». В PR создана самостоятельная CSS/SVG адаптация без побайтного копирования изображения из библиотеки.
- Новый фон: тёмно-синий океан, золотые акценты, корабль на закате, существующий пиратский жетон и SVG сундука.
- Все способы оплаты, включая скины Steam, карты, СБП, QR и Stars, остаются **строго демонстрационными**. Не отправляйте деньги или предметы через тестовые формы.

## Сборка и тесты

```cmd
py -3.11 -m pip install -r requirements.txt -r requirements-ui.txt pytest
py -3.11 -m pytest -q
node --check ui/app.js
node --test tests/browser_controls.test.cjs tests/skinpay_ui.test.cjs
```

После PR можно получить артефакт тестового Windows установщика из GitHub Actions, если его сборка пройдёт. Основной релиз автоматически не меняется до merge и публикации новой версии.
