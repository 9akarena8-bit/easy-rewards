# Fortnite Pirate Token — закрытая проверка для двух тестировщиков

Дата планирования: 12 ноября 2026 года. **Для ручной проверки используйте установщик из Windows CI интеграционного PR.**

## Важное ограничение сборок

**PR #26 (Fortnite/Anti-AFK) и PR #28 (Discord/QA) пока независимы.** Установщик из CI PR #28 собирает только QA-ветку и не содержит исправлений из PR #26. Установщик из PR #26, в свою очередь, не содержит QA-правок PR #28. **Ни один из этих двух файлов не выдавать за общую проверенную бету.**

Для сравнимых результатов оба тестировщика используют один установщик из интеграционной сборки и сверяют исходный SHA и SHA256. SHA256 ZIP-артефакта GitHub Actions не заменяет SHA256 установщика EXE: фиксировать хеш именно передаваемого EXE.

## Перед установкой

1. Получить **один и тот же** бета-инсталлятор, его версию, номер коммита и SHA256 из отмеченного запуска GitHub Actions; никогда не брать exe из неизвестного Telegram-канала.
2. Установить на Windows 10/11, отметить версию Windows, видеорежим Fortnite (эксклюзивный fullscreen / окно / безрамочное), разрешение экрана и версию бета-инсталлятора.
3. Не вводить в отчёт пароли, Steam API, лицензии, токены бота, Discord webhook и платёжные реквизиты.
4. **Демонстрационная оплата не принимает деньги или предметы.** Тестировщики не должны отправлять переводы/скины. Программа не является продуктом Epic Games и не гарантирует внутриигровые награды.

## Тестировщик 1 — Fortnite, окно, Anti-AFK, управление

- [ ] Открыть лаунчер с закрытым Fortnite. Проверить, что статус говорит «не найдено», а не «работает».
- [ ] Запустить Fortnite вручную; убедиться, что диагностический статус нашёл **видимое** окно игры (не служебное EAC/EOS).
- [ ] Проверить полноэкранный и оконный/безрамочный режим; при сворачивании/Alt+Tab состояние должно обновляться корректно.
- [ ] Выполнить Start→Stop, включая остановку во время ожидания окна, затем Start→Stop→Start. Кнопки, F8 и аварийная F12 должны отвечать.
- [ ] Проверить F10 Пауза→Продолжить; после потери фокуса программа не должна продолжать ввод самостоятельно без явного подтверждения.
- [ ] Проверить лобби и HUD: движения не должны начинаться до подтверждения HUD; проверить ограничение повторных кликов, пустые/отсутствующие шаблоны.
- [ ] Указать, если игра блокирует обычный ввод. Не пытаться обходить защиту или маскировать процесс.

## Тестировщик 2 — лаунчер, новости, Discord и демо-платежи

- [ ] Проверить запуск, все пункты меню, масштабирование, клики, работу вкладок после 10 минут обновления статуса без прыжков прокрутки.
- [ ] На главной и странице «Новости» открыть **полный текст** как минимум одного релиза; проверить локальные заметки без сети, дату и версию.
- [ ] Проверить «Проверить обновление»/ошибку отключённой сети, отсутствие зависания интерфейса.
- [ ] Discord: с **тестовым** собственным webhook — включение/отключение/тест, обработку неправильного URL и сетевой ошибки, отсутствие URL в отчёте и UI; удалить тестовый webhook после проверки.
- [ ] Создать только демо-черновики подписки/перевода/СБП/QR/Steam; проверить пустую корзину, ошибки сумм, отключённую покупку и **отсутствие выдачи лицензии**.
- [ ] Проверить отчёт поддержки и, перед отправкой, убедиться, что в нём нет личных данных.

## Один формат отчёта

```text
Тестировщик: #1 / #2
Версия программы:
Git SHA:
SHA256 установщика:
Windows:
Fortnite: версия / режим окна / разрешение:
Сценарий и точные действия:
Ожидалось:
Фактически:
Лог (секреты удалены):
Скриншот/видео (без личных данных):
Повторяется: всегда / иногда / один раз
```

**Критерий готовности к объединению:** зелёные Python/JS/Windows CI по конкретному SHA; нет критических регрессий; работа на живом Fortnite подтверждается **отдельно** от автоматизированных тестов. Без подтверждения не заявлять об «исправленном фарме».
