# Fortnite Pirate Token — проверка v1.4.3 UI / двух тестировщиков

> Документ QA; **не означает, что функции реализованы**. База: `main`/v1.4.2. Итоговый build и release только после объединения утверждённых PR, CI + двух ручных Windows smoke тестов. Никаких реальных платежей до серверного подтверждения и юридической проверки.

## Правила тестирования

- Прогоны выполняются на **одном одинаковом SHA256-проверенном EXE** на Windows 10/11. Тестировщик A: функциональные кнопки и окно Fortnite; тестировщик B: UI, подписка-демо, новости, язык, уведомления, восстановление.
- Записать: версия EXE, SHA256, Windows build, масштабирование экрана (100%/125%/150%), разрешение (1366x768 / 1920x1080), название процесса Fortnite и время отказа.
- Не вводить платёжные реквизиты/секреты Discord в публичные отчёты. Не объявлять «работает в Fortnite» без реально воспроизведённого сценария; не пытаться обходить античит.

## Критерии готовности

1. PR всех затронутых модулей сверены с общей базой, старые PR не сливаются без выборочного аудита.
2. Все GitHub Actions checks **green** именно на интеграционном SHA.
3. Одинаковый тестовый EXE + SHA256 у обоих тестировщиков.
4. Два отчёта ручных Windows-проверок, список воспроизводимых ошибок и подтверждение исправлений.
5. `SALES_ENABLED=0` до настоящего end-to-end сервера оплаты/лицензий.
6. Только после этого готовится релиз, а дату/ссылку публикуют в GitHub Releases.
