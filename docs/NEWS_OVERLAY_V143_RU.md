# v1.4.3 — новости: утверждённый модальный читатель
* Источник: реальные GitHub Releases, включая Beta; текст не сокращается до 380 символов.
* Центрированный широкий модал поверх затемнённой и размытой ленты, не боковая колонка.
* Клик на патч/первую карточку открывает полные заметки; «К новостям», ×, Esc и нажатие на фон закрывают.
* Фокус возвращается к карточке, базовая страница не прокручивается под модалом, внутри документа одна прокрутка.
* Каждую запись экранируем: GitHub Markdown отображается как обычный текст/заголовки/пункты без внедрения HTML.
* Старые патчи доступны в списке без искусственного ограничения 6 карточек; миниатюры отличаются инструментами/шестернями.
* Заметки с фактическими датами; если дата отсутствует — не выдумывать. Без старых фейковых новостей.
* Окончательную полноту описания v1.4.2 берём из опубликованного release body; подробный локальный CHANGELOG остаётся отдельным источником до последующей интеграции.

Изменения изолированы от Anti-AFK, платежей, главного оформления и ветки Codex.
