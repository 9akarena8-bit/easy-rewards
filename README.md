# Easy Rewards v1.3.4 — стабильный Anti-AFK и «Играть снова»

**Это полный проект** на основе объединённой v1.3.3 (Fortnite Pirate Token + Anti-AFK), а не отдельный патч. Дизайн, трекер, обновления GitHub и демо-подписки сохранены.

## Что исправлено в v1.3.4

- Приложение умеет **без готовых шаблонов** искать жёлтую кнопку «ИГРАТЬ СНОВА» на правой стороне экрана результатов Fortnite. Поиск ориентируется на её форму, цвет, положение и соседнюю светлую панель; число в надписи «ВЫ ЗАНЯЛИ #5» никак не используется.
- «Вернуться в лобби» и «Остаться в команде» не нажимаются. Для цветового распознавания нужны **3 последовательных подтверждения**, чтобы уменьшить число случайных нажатий.
- При обнаружении «Играть снова» движение приостанавливается, затем кнопка нажимается, программа ожидает её исчезновения и минимум 6 секунд на загрузку следующего матча. Если экран остаётся, допускается **максимум три нажатия с интервалом не менее 6 секунд** — дальше приложение останавливает попытки и выводит предупреждение.
- По желанию можно сохранить точный шаблон `Replay` через кнопку во вкладке «Анти-АФК» — он имеет приоритет над цветовым поиском. При изменении игрового интерфейса или масштаба это надёжнее.
- Нажатие F7 сразу после F8 не теряется: запуск ставится в очередь до полной остановки предыдущего потока.
- Повторные попытки перенести фокус в игру ограничены по частоте, чтобы программа не дёргала окно каждые полсекунды. Дополнительно исправлены 64-битные сигнатуры Windows для `SetForegroundWindow` / `ShowWindow`.
- Добавлен счётчик нажатий «Играть снова» и состояние ожидания/загрузки во вкладке «Анти-АФК».

**Важно:** автоматическое распознавание зависит от оформления экрана (в частности, жёлтая кнопка должна быть в правой средней области и над ней должна быть светлая кнопка лобби). Изменения UI Fortnite могут потребовать сохранения собственного шаблона. Нельзя гарантировать, что Fortnite принимает ввод Windows SendInput; полноценную проверку на защищённом Windows-клиенте нужно проводить отдельно. Приложение не обходит античит. Автоматизация может нарушать правила игры.

## Как проверить

1. В версии v1.3.4 открой «Анти-АФК», убедись, что включены «Анти-АФК», «Случайные сценарии» и «Находить жёлтую кнопку «Играть снова» автоматически».
2. Запусти Fortnite, нажми F7 **в окне игры**, проверь статистику «Выполнено действий». F8 — остановить, F10 — пауза.
3. После смерти открой экран результатов (жёлтая кнопка справа, как на присланном скриншоте), не переключаясь в другие приложения. В статусе должны последовательно появляться «Кнопка обнаружена», «Нажата, идёт загрузка», «Матч продолжается». Счётчик «Нажатий «Играть снова»» должен увеличиться.
4. Если кнопка не распознаётся, сохрани её образец: «Анти-АФК» → «Сохранить точную кнопку» → «Захватить» (за 5 секунд вернись к экрану результатов) → выдели **только кнопку ИГРАТЬ СНОВА** → «Сохранить»; затем проверь «Тест шаблонов».
5. При странных результатах отдельно проверь F6 и тест Блокнота. Эти тесты проверяют отправку событий Windows, а не гарантируют реакцию Fortnite.

## Публикация разработчиком

1. `PUBLISH_GITHUB.bat` → `YES`, затем создать и объединить Pull Request в `main`.
2. `TAG_RELEASE.bat` → `RELEASE` **только после merge**.
3. После успешной сборки GitHub Actions появится `EasyRewards_Setup_1.3.4.exe`, и установленная v1.3.3 увидит обновление через приложение.

Исходный ZIP не требуется обычным пользователям: они обновляются через опубликованный установщик. Текущий релиз не опубликован автоматически этой сборкой ZIP.

# Easy Rewards v1.3.3 — исправления Anti-AFK

Исправленная версия исходного Easy Rewards v1.3.2 без изменения дизайна.

## Как проверить ввод в Windows 10

1. Установить новую версию и убедиться, что внизу лаунчера указано **v1.3.3**.
2. Открыть Easy Rewards → **Анти-АФК** и включить **Анти-АФК** и **Случайные сценарии**.
3. Нажать **«Тест в Блокноте (W)»**, сразу переключиться в открытый Блокнот с курсором в текстовом поле. Примерно через 3 секунды должна появиться буква `w` (или `ц` при русской раскладке). Тест сам ничего не меняет в игре.
4. Нажать **«Проверить ввод через 3 секунды»**, переключиться в Fortnite, зайти в матч. Программа кратковременно удержит `W`. Либо нажать **F6** прямо в игре для такого же теста.
5. Вернуться в Easy Rewards → Анти-АФК и посмотреть «Последняя проверка». Если «Команда отправлена в Windows», но в игре не было движения, игре мог не подойти стандартный ввод Windows. Тест не проверяет игровую реакцию, он лишь сообщает результат Windows API.
6. На странице анти-АФК нажать **«Запустить»** (или **F7** из активного Fortnite), вернуться в игру. Движения начнутся только при активном Fortnite. **F8** остановка, **F10** пауза/возобновление.
7. Если видишь «Fortnite не найден» или «Окно не активно», проверь, что игра запущена, её окно на переднем плане, а лаунчер не перекрывает игру.

Если тест в Блокноте не печатает букву, пришли скриншот вкладки **Анти-АФК** со статусом теста и журналом ошибок. Если Блокнот работает, а Fortnite нет — стандартный SendInput может игнорироваться игрой. Данный проект не обходит игровые средства защиты и не гарантирует работу в защищённой игре.

## Что изменено

- Исправлена диагностика ожидания окна: *окно не найдено / не активно / анти-AFK выключен*.
- **F6** и две диагностические кнопки в анти-АФК: Fortnite и Блокнот.
- Неблокирующая остановка движка при долгом захвате экрана, проверки отмены в распознавании шаблонов.
- Защита от случайной отправки в окно, лишь упоминающее Fortnite в заголовке.
- Сохранены настройки движения (W/A/S/D, диагонали, прыжки, спринт, подкаты, камера, переключение слотов), опциональные действия, распознавание Death/Replay, демо-подписки и фоновые проверки GitHub Releases.
- Опустошение магазина по распознаванию патронов и автоматический выброс всего инвентаря по-прежнему не реализованы.

## Публикация

1. Распаковать полный исходный ZIP в **отдельную папку** и запустить `PUBLISH_GITHUB.bat`. Подтвердить `YES`.
2. Открыть ссылку в CMD, проверить и объединить Pull Request в `main`.
3. Запустить `TAG_RELEASE.bat`, подтвердить `RELEASE`.
4. Дождаться зелёной галочки GitHub Actions для тега **v1.3.3** и релиза `EasyRewards_Setup_1.3.3.exe`.
5. На установленной Easy Rewards v1.3.2 получить уведомление об обновлении, либо открыть вкладку «Обновления». Закрыть работу программы и подтвердить установку.

Само создание ZIP не обновляет установленную программу и не публикует релиз. Публикация нужна один раз разработчику; конечным пользователям не нужны исходники, Git и CMD.
