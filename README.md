# Easy Rewards v1.3.2 — Updates & Subscriptions Preview

Windows 10/11 (64-bit), Python 3.11 source. Previous Anti-AFK v1.3.0 behavior is preserved.

## Что нового
- Проверка официальных GitHub Releases **каждые 5 минут** (если включены автообновления).
- Фоновая загрузка и проверка SHA-256 нового установщика, без отключения текущей сессии.
- Баннер доступного обновления. Кнопка **«Выйти и обновить»** запускает уже проверенный установщик и закрывает приложение. Установщик Inno Setup нужно подтвердить и завершить обычным способом; возможен запуск новой версии в конце установки. Полностью бесшумной установки нет.
- На вкладке **«Подписки»** видны демо, 24 часа, 3 дня, 7 дней, оставшееся время (пока «—»), будущие предупреждения и будущая оплата картой/СБП.
- **Все подписки/активации/платежи ОТКЛЮЧЕНЫ.** Оплатить, получить демо или заблокировать функции пока нельзя. Здесь нет сервера лицензирования и нет реальной платёжной интеграции. Это только безопасный предпросмотр интерфейса. Скрытой админ-панели в этом релизе нет.

## Выпуск обновления
1. Распаковать ZIP, запустить `PUBLISH_GITHUB.bat`, подтвердить `YES`.
2. По ссылке на GitHub открыть Pull Request и сделать Merge в main после проверки.
3. Запустить `TAG_RELEASE.bat` и подтвердить `RELEASE` — он отправит `v1.3.2`.
4. Убедиться, что GitHub Actions завершился без ошибок и в Releases появился `EasyRewards_Setup_1.3.2.exe`.
5. Уже установленная v1.3.0 увидит новый релиз при запуске или при ручной проверке; после установки v1.3.2 начнут действовать пятиминутные проверки и фоновая загрузка.

## Тестирование
```cmd
py -3.11 -m pip install -r requirements.txt -r requirements-ui.txt pytest
py -3.11 -m pytest -q
```

Программа использует стандартный Windows SendInput; Fortnite может не принимать такой ввод. Автоматизация может нарушать правила игры. Локальная сборка Windows на этом окружении не проверена.
