# Easy Rewards v1.3.0 — Anti-AFK sequences

Windows 10/11, 64-bit · отдельный проект, не связанный с Epic Games.

## Новое

Отдельная вкладка **Анти-АФК** с настраиваемым случайным сценарием:

- Ходьба **W/A/S/D**, диагонали **W+A / W+D / S+A / S+D**.
- **W+Shift**, **W+Shift+Space**, **W+Shift+Ctrl**, **W+Shift+Ctrl+Space**.
- Отдельные **Space**, **Ctrl**.
- Камера: вращение влево/вправо до 360°, вверх/вниз на 45/90/180° и попытка вернуть угол к центру. Угол приблизительный: зависит от чувствительности Fortnite; калибровка в настройках «Пикселей на 360°».
- Смена слотов 1, 2, 3, 4, 5, 6, без повторения одного слота подряд.
- По **явному включению**: ЛКМ (кирка), Y + ЛКМ (бросок), слот 2 + ПКМ + ЛКМ (короткий залп, максимум 1,5 секунды).
- Пауза между действиями случайная, по умолчанию от **0,5 до 2,0 секунд**; длительность регулируется.
- Не выбираются одинаковые действия подряд; никакой гарантии похожести на человека или обхода анти-AFK/античита нет.

## Смерть и «Играть снова»

Приложение анализирует картинку через **локальные шаблоны**. Это не универсальное распознавание без предварительной настройки.

1. Во вкладке **Шаблоны** выбери **Экран смерти (ожидание)** и сохрани небольшой узнаваемый прямоугольник из экрана смерти.
2. Сохрани шаблон **Играть снова (автонажатие)**, захватив кнопку на экране после смерти.
3. Протестируй совпадение скриншотов (порог по умолчанию 0.80). В идеале должны совпадать в правильном состоянии и не совпадать в лобби/матче.
4. Запусти сценарий. При обнаружении Death все действия приостанавливаются, до появления Replay. При Replay приложение нажимает кнопку и продолжает сессию. Если кнопки не видны или распознать их не удаётся, движок не может гарантированно определить смерть.

При наличии ещё и шаблонов Start/Result ранее существовавшее управление стартом/результатами сохраняется.

## Безопасность и ограничения

- **F7** начать, **F8** стоп, **F10** пауза/продолжить, **F9** ручной счётчик.
- Ввод новой системы работает только когда Fortnite — активное окно. При остановке, паузе и переключении окна длительные удержания прерываются, клавиши отпускаются.
- Нет внедрения в процесс, чтения памяти, драйверов и обхода античита. Используется стандартный Windows SendInput; Fortnite может не принять синтетический ввод.
- **Не реализовано** надёжное определение количества патронов, полного опустошения магазина и автоматическое выбрасывание вещей из инвентаря. Включаемая стрельба ограничена по длительности. Ничего из инвентаря автоматически не выбрасывается.
- Опциональная стрельба, удары и броски могут расходовать ресурсы и делать действия в игре — включай осознанно.
- Автоматизация игрового процесса может нарушать правила Fortnite и приводить к блокировке.

## Проверка исходников

Python 3.11 x64:

```cmd
py -3.11 -m pip install -r requirements.txt -r requirements-ui.txt pytest
py -3.11 -m pytest -q
py -3.11 app.py
```

На Windows можно просто запустить `run.bat` либо собрать свой установщик с помощью `BUILD_INSTALLER.bat` (потребуется Inno Setup).

## Публикация обновления v1.3.0 через GitHub

1. В Windows распакуй этот ZIP в папку; запусти **PUBLISH_GITHUB.bat**. Скрипт создаст ветку `feature/easyrewards-v1.3.0`, не заменяя main.
2. Перейди по ссылке, которую выведет скрипт, создай и проверь Pull Request, затем выполни Merge.
3. Лишь после Merge запусти **TAG_RELEASE.bat** и введи `RELEASE`.
4. На GitHub Actions должна успешно завершиться сборка `Build Windows Installer` для тега v1.3.0. Готовый `EasyRewards_Setup_1.3.0.exe` будет в разделе Releases после успешной сборки.
5. Уже установленная версия 1.2.4 должна обнаружить опубликованный Release и предложить запустить установщик из программы. Установка требует подтверждения пользователя.

Скрипты публикации используют локальный Git пользователя, не хранят токены.

Настройки и статистика установленного приложения хранятся в `%LOCALAPPDATA%\EasyRewards`. Установщик располагает приложение в `%LOCALAPPDATA%\Programs\EasyRewards`.
